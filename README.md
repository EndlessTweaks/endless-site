# Endless website

Static site source for GitHub Pages. Open `index.html` locally to preview it; no
build step or external JavaScript libraries are required.

## Publish

The site is published at <https://endlesstweaks.github.io/endless-site/> from
the public, site-only repository <https://github.com/EndlessTweaks/endless-site>. The
included GitHub Actions workflow deploys the static site after each push to
`main`.

## Product download links

The Endless Tweaks consumer download points to the latest GitHub Release asset
in `EndlessTweaks/endless-site`. Endless Zero sign-in calls
`https://endless-tweaks-license-api.onrender.com`. It has Sign in and Create
account actions matching the desktop account screen, and checks the Lifetime
Pro code for entitlement. Website passwords are salted PBKDF2 hashes held on
the license service; they are separate from local desktop app accounts. The API
streams the Zero archive from its private persistent disk. The ZIP must not be
attached to a public GitHub release or copied into the public Pages repository.

The current consumer release is `v1.1.0`:

- `EndlessTweaks-Consumer-win-x64.zip`

`endless-logo-purple.png` is the shared Endless brand asset used in the header
and footer.

Endless Zero is included with the Endless Tweaks Lifetime Pro plan. The app
requires a valid Pro activation at launch and shares the activation already
redeemed in Endless Tweaks for the same Windows user account. The website
accepts the matching username and code before streaming the ZIP; the short-lived
download token is kept only in page memory.

## Enable the secure Zero download

`render.yaml` is a Render Blueprint for the API. Create a Blueprint from this
repository, select the configured paid web plan and 1 GB persistent disk, then
wait for `/health` to return successfully. The web API URL is configured in
`index.html` as `https://endless-tweaks-license-api.onrender.com`.

Upload the ZIP to the disk using the API admin secret generated by Render. Run
in PowerShell and enter the secret and local archive path when prompted:

```powershell
$adminSecret = Read-Host "Render ENDLESS_ADMIN_SECRET"
$zipPath = Read-Host "Path to EndlessZero-Consumer-win-x64.zip"
Invoke-RestMethod -Method Put -Uri "https://endless-tweaks-license-api.onrender.com/api/admin/package" -Headers @{ "X-Admin-Secret" = $adminSecret } -ContentType "application/zip" -InFile $zipPath
```

Create a website account with the username, password, and Pro code that match
your Endless Tweaks Pro username. Later, sign in with those same details. The
API verifies server-issued online codes without consuming unused codes and
verifies signed offline `BT1` owner codes with the app's public verification
key. Successful sign-in tokens expire after 15 minutes. Until the Blueprint is
deployed and the archive uploaded, the download form reports that the secure
service is unavailable.

When previewed locally with `file://`, the Endless Tweaks button points to the
workspace artifact; Endless Zero still needs the hosted secure API. The hero
panel's animated CPU and memory figures are decorative sample values, not
readings from a visitor's computer.
