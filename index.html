System requirements & installation

Windows 10 or Windows 11, 64-bit x64. Hardware-specific settings depend on your device and Windows build. Some changes require administrator access.

  1. Download the official standalone EXE.
  2. Open it and review the Windows prompts.
  3. Review compatibility and descriptions before applying settings.

Updating an existing install? Use Update Center in the app to retain its install path and rollback copy.

File verification

The updater verifies the publisher-signed manifest and package hash before installation. A GitHub download hash checks file integrity; it is not a Windows code-signing certificate.

Our approach

Useful beats
overhyped.

A tweak cannot make every PC behave the same way. We explain what a setting changes, what it may affect, and how to restore it.

01 · CLEAR

Settings include descriptions so you can decide whether they fit your setup.

Measure your own PC

Results depend on hardware, Windows, drivers, and the game—not a blanket promise.
